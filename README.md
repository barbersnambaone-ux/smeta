# Смета AI 0.6 Cloud — демоверсия

Веб-сметчик Streamlit: Excel-ведомости, нормативы производителей, подбор артикула, расчёт упаковок, ручное подтверждение цены с сайта Петровича для Москвы, экспорт Excel.

## Важно

**Автоматический сетевой парсинг НЕ реализован.** Публичный API цен для сторонних клиентов не подтверждён. Для проверки товара пользователь открывает страницу Петровича в своём браузере, вставляет текст или загружает сохранённый HTML. Приложение извлекает **кандидаты** цен и кодов, затем сотрудник подтверждает нужную цену. На странице могут быть цены по карте, акции, сопутствующие товары — выбор автоматом небезопасен.

Нормы из учебных файлов **не являются утверждёнными техническими нормами**. Замените на проверенные технические карты производителей, с источниками и датами. Цены в sample_data также учебные. История цен хранится в Streamlit session_state (только до сброса сессии), экспортируется CSV. Для постоянной истории нужна внешняя база данных.

## Публикация без локальной установки

1. Создайте репозиторий GitHub и загрузите файлы из этой папки **в корень репозитория**.
2. Откройте https://share.streamlit.io/ и авторизуйтесь через GitHub.
3. Создайте приложение, выберите репозиторий, ветку `main`, файл `app.py`.
4. После Deploy откройте полученную ссылку `.streamlit.app`.
5. Используйте только тестовые данные в публичной демоверсии; реальные сметы требуют закрытого доступа.

Для запуска разработчиком: `pip install -r requirements.txt && streamlit run app.py`.

## Дальнейшая интеграция

При наличии официального разрешённого API или выгрузки от Петровича можно добавить автоматический адаптер. Не следует обходить блокировки, авторизацию или ограничения доступа сайта.
